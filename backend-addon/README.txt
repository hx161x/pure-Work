PURE WORK MOBILE BRIDGE 1.0.0

Optional, aber empfohlen für die native App.

Installation in WordPress:
1. Den Ordner pure-work-mobile-bridge als ZIP packen oder den beiliegenden ZIP verwenden.
2. WordPress → Plugins → Installieren → Plugin hochladen.
3. Aktivieren.

Das Plugin registriert pro eingeloggtem Benutzer bis zu fünf Mobile-Device-Tokens und stellt Deep-Link/Haptik-Schnittstellen bereit.
Für echte Push-Zustellung sind zusätzlich APNs/FCM-Zugangsdaten nötig.
